# GPT-Small: 125M Parameter Language Model

## Overview

GPT-Small is a 125-million-parameter language model developed using PyTorch. The project explores the fundamentals of transformer-based language modeling, focusing on self-attention, token prediction, and autoregressive text generation.

The model is based on the GPT-2 Small (125M parameter) architecture, providing a foundation for understanding how transformer language models process text and learn language patterns.

## Key Features

* **125M Parameters:** Compact language model architecture.
* **Self-Attention Mechanism:** Learns relationships between tokens in a sequence.
* **Autoregressive Text Generation:** Predicts the next token based on previously processed tokens.
* **PyTorch Implementation:** Built using PyTorch for model development and training.
* **Training Pipeline:** Supports model training, loss calculation, optimization, and evaluation.
* **GPU Acceleration:** Supports CUDA-enabled GPU training.
